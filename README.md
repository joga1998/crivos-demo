# CRIVOS // Painel Demonstrativo de Alta Performance (Standalone)

Sistema Operacional de Estudos pós-edital sob demanda calibrado para o **PPGHS / UERJ 2027** (Área: História Social do Território).

Esta versão é o **ambiente de demonstração pública e interativa** da CRIVOS:
- 100% autônomo (não requer banco de dados, login ou credenciais externas).
- Totalmente funcional no navegador do candidato via `localStorage`.
- Inclui todas as 12 ferramentas ativas: Cronograma Elástico, Fichas de Leitura, Flashcards SM-2, Pomodoro Tático, Simulados com Espelho de Correção, Treinamento de Arguição Oral, Conexões Conceituais, Repositório de Arquivos, Dicas de Engenharia, Backup JSON e Perfil do Candidato.
